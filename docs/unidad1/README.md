# Entregables de la Unidad 1

En esta carpeta se conservan los entregables desarrollados durante la Unidad 1 y la documentación asociada a las retroalimentaciones recibidas.

## Entregables

- `Avance1_Equipo 7.pdf`: propuesta de valor, desafío, alcance preliminar y usuarios del proyecto.

Los archivos originales evaluados se conservan sin modificaciones.
