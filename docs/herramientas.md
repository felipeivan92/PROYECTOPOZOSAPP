# Herramientas de la solución

Las herramientas se definen según la función que deben cumplir dentro del flujo del MVP.

| Función | Herramienta o componente |
|---|---|
| Incorporar datos de monitoreo | Importación de archivos CSV o Excel |
| Detectar anomalías | Procesamiento mediante reglas de validación |
| Comparar información de distintas fuentes | Cruce de registros DGA y LI-COR |
| Almacenar pozos, datos, eventos y tickets | Base de datos |
| Visualizar anomalías priorizadas | Interfaz web |
| Revisar evidencia | Vista de detalle del evento |
| Registrar decisiones y acciones | Módulo de gestión |
| Mantener trazabilidad | Relación entre evento, evidencia, gestión y ticket |
| Diseñar y validar las pantallas | Figma |
| Gestionar versiones y trabajo colaborativo | GitHub |
| Apoyar análisis y documentación | IA generativa con revisión humana |
